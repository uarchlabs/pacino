# Task Overview
Pacino's physical address width moves to 48 bits, for physical memory
of the Sv57 data-center class (Jeff, session-085;
l1i_ifu_interfaces.md IF-1). This is a width-only task, like BP-145:
1. Every physical-address width in the RTL and its testbenches follows
   PA_WIDTH, and every test whose stimulus is meant to be outside the
   physical space forms that stimulus from PA_WIDTH or PPN_WIDTH. At
   today's width the affected targets give BP-146's results.
2. PA_WIDTH becomes 48, and everything derived from it follows. The IA
   edits the pacino copy of the L1I to the new width
   (icache_decisions.md L1I-20); cachegen is not changed (TD#199).
3. Directed cases show a full 48-bit physical address used end to end.

The ITLB's modes, tb_fe_top on pt_build_pkg and the Sv48 and Sv57
programs are the next task, BP-148.
