# Task Overview

BP-129 sized the history correction after a backend mispredict by
NUM_PRED_SLOTS, so at one slot it carries one bit. When the backend
mispredicts a block's second branch, which at one slot is held in no
slot, the correction then drops the first branch's not-taken bit, and
six tb_fe_top programs mispredict more. Jeff ruled that the correction
carries up to two bits at either slot count. This task widens the
correction path to two bits, so at one slot both bits reach the
history again. The prediction inputs to bp_history stay sized by
NUM_PRED_SLOTS. At two slots nothing changes.
