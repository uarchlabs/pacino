## Background
Each item is taken from a task record or a planning document. The PA
has not checked any of them against the tree; check each one.

- TD#182, from BP-133 Other Notes 1. tage_cntrl.sv pred_logic sets the
  provider counter for T0 to the 2-bit counter zero-padded to 3 bits,
  {1'b0, ctr}. The confidence decode and tage_extd_ctr then treat it as
  a 3-bit tagged counter. BP-133 reported the result:
    T0 00 (strong NT) -> 000: strong,  extd -7
    T0 01 (weak NT)   -> 001: medium,  extd -5
    T0 10 (weak T)    -> 010: medium,  extd -3
    T0 11 (strong T)  -> 011: weak,    extd -1
  So a T0 predicting taken gives SC a not-taken TAGE term, and a
  strongly taken T0 is flagged weak. T0 resets to 2'b10, so every
  T0-provided prediction starts this way. SC sums tage_extd_ctr in
  sc_cntrl.sv.
- tb_tage's extd_ctr test covers a tagged provider only (BP-133 Other
  Notes 1).
- BP-126 Deferred Work: tb_tage's older tests change their inputs in
  the same time step as the sampling edge, a latent race. No TD.
- ras.sv commit_rctr: written zero at reset and on every commit push,
  read by nothing (BP-133 Problem 3). The commit stack keeps recursion
  depth as repeated entries.
- BP-133 Deferred Work: a plain undo of a push (st_retract) at a
  saturated recursion count decrements a count the push did not raise,
  so one recursion level is lost in that case. BP-133 D4 left it.
- BP-133 Deferred Work: no tb_fe_top program reaches an undo over a
  recursion-decrement pop. BP-133 Problem 2 says the case is reachable
  when SC reverses an earlier conditional in a block so that a return
  reachable at p2 is not reachable at p3.
- ubtb_interfaces.md, Timing: ubtb.sv's header comment says the
  outputs are "combinational from registered mem" and valid one cycle
  after pred_pc_p0. They are combinational from pred_pc_p0, valid
  within the p0 cycle; mem is a flop array read combinationally.
- Session-073, carried comment-only: ftq_meta.sv and tb_ftq_meta.sv
  say 421 bits; bp_ftq_meta_t is 425 bits per slot since BP-111.
  tb_ittage_cntrl.sv helpers chk38 and chk57 are named for widths that
  are 40 and 59 since BP-111.
- Session-073, carried comment-only: the comment in ftq_ifu.sv above
  the flush always_comb, and ftq_ptr.sv near lines 403-405, still say
