# Task Overview

Write sc.sv, the SC structural top, plus tb_sc.sv and its tests.
sc.sv instantiates sc_cntrl, the five SC tables (sc_table ST0-ST3 in
a generate loop, sc_brimli ST4), and one sram_init. It fans the
sc_cntrl table-facing t_* port set to the table ports, adapts the
index-bus widths between the uniform SC_MAX_IDX_WIDTH controller
buses and the per-table THIS_INDEX_BITS, drives the sc_brimli index
inputs, applies the SC_FAST_INIT parent tie-off mux over sram_init,
gates prediction/update on sc_ready, and presents the sc_interfaces
top-level port set (stubbing the arbitration-layer ports that have
no producer yet). Structural only: sc_cntrl and the tables are fixed;
transcribe the connections, add no control logic.

## Decisions made not explicit in the prompt
- sc_upd_rdy arb-status: driven to the safe constant
  {NUM_PRED_SLOTS{1'b1}} (all-ones). With no SC UQ in this unit the
  update channel always has room; this parallels tage's upd_rdy when
  the UQ is never full. (The prompt allowed a safe constant or
  passthrough; constant chosen.)
- -Wno-SYNCASYNCNET added to lint_sc/sim_sc/sim_sc_fast in addition
  to the -Wno-VARHIDDEN allowed by Constraints. sram_init uses an
  async reset (posedge clk or negedge rstn) while sc_cntrl and the
  tables use rstn as a sync reset, so rstn is a mixed sync/async net
  -- Verilator SYNCASYNCNET. This is structural and identical to the
  established tage.sv / ittage.sv parent-top targets, which suppress
  it the same way. It arises solely from instantiating sram_init, not
  from any logic added in sc.sv. Flagged here because it is beyond the
  single suppression (VARHIDDEN) named in the Constraints.
- -Wno-VARHIDDEN required: sc, sc_cntrl, sc_table and sc_brimli each
  declare a NUM_PRED_SLOTS parameter that shadows the package
  parameter (sc_cntrl's header comment already mandates it).
- Generate-loop / instance names chosen for stable hierarchical tb
  paths: gen_st (loop), u_st (sc_table), u_st4 (sc_brimli),
  u_sc_cntrl, u_sram_init.
