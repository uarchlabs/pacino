### Problem 1 -- the tag gate (tools/publish_waves.py resolve(), 191)
- New shared module tools/fe_release.py has the tag rule:
  TAG_RE fe-(0|[1-9][0-9]*)\.(0|[1-9][0-9]*)\.(0|[1-9][0-9]*), matched
  in full, ASCII digits only. parse_tag() returns the version and
  latest_tag() picks the latest. Both publish_waves.py and docs.yml
  use it.
- Options: --tag, --commit (full 40-character sha), --untagged,
  --dry-run, --out, --no-build (dry run only), --published.
  - --tag T --commit C: no git call at all.
  - --tag T alone: git checks that T is annotated
    (cat-file -t refs/tags/T == tag), finds its commit
    (rev-parse refs/tags/T^{commit}), and requires HEAD == that commit.
  - No options: the git lookup lookup_head_tag() (150) runs rev-parse
    HEAD, then for-each-ref --points-at HEAD
    --format='%(objecttype) %(refname:strip=2)' 'refs/tags/fe-*'. Only
    objecttype "tag" (annotated) with a valid name counts. Lightweight
    or invalid names get a [note] line and are ignored. With none
    left, the script refuses; with several, the latest is used.
  - --commit C without --tag or --untagged: refused.
  - --untagged with --tag: refused.

### Problem 3 -- the digest and the staleness report
- sucl_signals(): the variable_add names in a .sucl (Surfer names).
- scenario_digest(): maps those names to FST paths through
  fe_demo_sigs.fst_names() and reads the value changes with
  fe_demo_sigs.fst_values(). Both read the FST with FST2VCD from
  rtl/Vars.mk, so the FST bytes are never digested.
- digest(values, names): sha256 over the listed signals in name order.
  Each signal is hashed as "S <name>" and then "<time> <hex|x>" lines.
- canonical(): keeps the last value at each time and drops a value
  equal to the one before it.
- staleness() / report(): each scenario is unchanged, changed, new or
  "no published digest". A published digest_version other than 1
  counts as no published digest. A scenario that has gone from the
  build is listed as "removed". A changed digest prints [warning] and
  the run continues.
- The digests are computed and timed in every run, dry or real. Time
