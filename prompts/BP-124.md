## Background
BP-123 built the walker, the pacino L1I copy and the IFU's
maintenance and uncached paths, and passed tools/regress.sh with 149
targets. Its results raised three things Jeff ruled on:

- MMU-30 returned a guest physical address above bit 40 as 0. That
  collides with a kind-00 fault on guest page 0, whose GPA is also 0,
  so htval would lose the offset (BP-123 risk 1). A VS-stage PTE holds
  a 44-bit PPN, so a walk can form a 56-bit GPA; Shtvala requires
  htval to carry it.
- Under Svadu the walker set A on a single-stage or VS-stage leaf
  before the ITLB checked U against the privilege, so a fetch that
  then faulted on U could leave A set (BP-123 risk 2, D8). The
  privileged translation algorithm makes every leaf check (steps 6 to
  8) before the A/D update (step 9).
- The decoder mapped FP, AMO and CSR instructions onto placeholder
  operations before BP-123, and BP-123 (D4) mapped the SYSTEM fences,
  HLV/HLVX/HSV, WRS and FLH/FSH onto the representation already used
  for their class, so a backend could not tell those operations
  apart (risk 3). Reading the decoder in session-077 also found
  reserved encodings in those spaces accepted, which RVA23 recommends
  raising illegal.

BP-123's D1, D2, D3, D6 and D7 were accepted as built and are in the
planning documents. D2's access-type port was built on the walker
only and tied to execute in tb_fe_top; Problem 2 has the ITLB drive
it.

## Problem 4: W1, W2 and W3U, from the RTL
A writeback with ifu_ftq_uc_end set is accepted as any writeback, and
ftq_ifu forms pd_redir_* exactly as for a predecode redirect (a
mis_val writeback whose entry has no earlier writeback):
- W1 (ftq_ifu.sv predecode_correct, ftq_entry.sv pd_wr_*): the slot at
  mis_pos is rewritten. Placement: the lowest slot that is invalid or
  whose pos is at or after mis_pos; every slot above it is killed
  (slot_valid and taken cleared, pd_wr_kill). The new slot is:
  - slot_valid: the instruction at mis_pos is a control transfer
  - br_type: its predecode class
  - taken: a control transfer that is not a conditional
  - target: ifu_ftq_target for a direct transfer, else the entry's
    slot[0] target
  - pred_src PRED_NONE, confidence 0
  For the usual uncached case (a non-CFI first instruction) the slot is
  written invalid, NO_BRANCH and not taken, and every later slot is
  killed. For a conditional at mis_pos the slot holds the branch, not
  taken, with its own target. Under uc_end a conditional at mis_pos was
  not predicted taken, since a predicted-taken p0 ends the block and
  sets no uc_end.
- W2: pos = mis_pos, the identity conversion (FTQ_PD_POS_BITS ==
  FTB_BR_POS_BITS).
- Flush index F: the predecode arm wins (arm_win[2]) unless a backend
  redirect is presented in the same cycle. ftq_npc drives redir_self 0
  and RC_MISPREDICT, so ftq_ifu's flush block gives F = K + 1, where K
  is ifu_ftq_pdwb_idx (ftq_ifu_flush_idx = redir_idx + 1). This is the
  same index as any predecode redirect.
- The W3U successor is formed by ftq_ifu, in predecode_correct:
  w_corr_succ = pc + 2 * mis_pos + (is_rvc ? 2 : 4), the length taken
  from the predecode info at mis_pos. It replaces the W3 re-derivation
  and is presented as pd_redir_pc. ftq_npc only selects it on arm 2
  (w_sel_pc = pd_redir_pc).

   miss. ASID and VMID do not enter the drop condition, because a
   change of V changes which ASID is compared.
7. tb_fe_top models a privilege change as the trap redirect: sret_to
   (SRET at retirement sets the privilege and redirects to sepc), and a
   trap taken to S. No CSR file is modelled.
