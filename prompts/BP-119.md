# Task Overview

The front end, end to end. Builds the three units that do not exist
-- the instruction buffer, the ITLB and the PMP/PMA checker -- moves
decode onto the IFU's packet (TD#143), checks two session-075
rulings against built BPU and FTQ RTL, and builds the front-end top
that connects BPU, FTQ, IFU, L1I, ITLB, ibuf and decode, with a
testbench that fetches and decodes real programs through it.

Runs after BP-118. The top's tests redirect, and until BP-118 the
IFU cannot take a flush with requests in flight.

Deliberately large: one task, to test how far one IA session goes.

## Hypothesis
Each new unit is fully specified and can be built from its
documents. The integration will find disagreements between units
that each passed alone: port shapes, valid/ready timing, and
assumptions one testbench model made that the real neighbour does
not honour. Those are the findings this task exists to produce.

## Background
BP-115 to BP-118 built the IFU and finished the FTQ side of the IFU
boundary. The ibuf, ITLB and PMP/PMA checker have documents and no
RTL. Decode still takes the old predecode_pkt_t, which TD#143
retires. No front-end top exists; the BPU, FTQ and IFU have only
ever run against testbench models of each other.

Session-075 ruled every open item these need. In short: ibuf not
banked, one read ready, cleared by the backend redirect valid
(IBUF-U1, IBUF-12, IBUF-13); ITLB tracker depth a parameter, default
1 (ITLB-15), PTE permissions checked on every hit against current
privilege (ITLB-16), G-stage permissions in the walker (MMU-26), a
CSR input group (ITLB-17, MMU-11a), the invalidate port list
proposed here (ITLB-14); a PMA region table parameter with main
memory 0x8000_0000 to 0xF_FFFF_FFFF (MMU-15a); decode computes
vtype_hazard, passes ifu_pd_pkt_t through, raises no illegal on a
fetch fault, and treats C and Zcb as always on (DCD-17 to DCD-20);
RETURN_CALL trains uBTB, FTB and RAS (fe_decisions.md 7.2); the loop
predictor overrides only a slot the uBTB supplied
(ftq_bpu_interfaces.md 4); the top's boundary input groups and the
L1I's emitted path (FE-20, FE-21).

Problem 1. The instruction buffer, rtl/core/frontend/ibuf.
  Build it from ibuf_decisions.md and ifu_ibuf_interfaces.md.
  Accept, each with a check in its own testbench:
  - a block is accepted whole, and ready rises only with 16 entries
    free whatever the block's enable mask holds (IB-6, IBUF-4);
  - enabled slots are compacted on write, in order (IBUF-3);
  - an empty buffer bypasses a write to the read port in the same
    cycle (IBUF-7);
  - the read port presents up to 8 valid entries from the head in
    order, and one ready dequeues all of them (IBUF-9, IBUF-12);
  - the backend redirect valid clears it, and nothing else does
    (IBUF-8, IBUF-13);
  - depth is a parameter, default 64 (IBUF-11), and full, wrap and
    a write and a read in one cycle are covered;
  - every property shown to fire under fault injection.

Problem 2. The PMP/PMA checker, rtl/mmu/pmp.
  Build the one checker of MMU-10a, with MMU-11, MMU-11a, MMU-12 to
  MMU-15a.
  Accept:
  - PMP: TOR and NAPOT matching, the lowest-numbered matching entry
    decides, the L bit, M-mode with no match allowed, S and U with
    no match denied when any entry is implemented. State the
    reference you used for each rule; tools/spike/ is permitted;
  - PMA: the default region table of MMU-15a classifies an address
    in main memory and one outside it correctly, at both ends of
    the range;
  - the effective type combines the region with a PBMT input, most
    restrictive wins (MMU-U6);
  - the region table and the PMP entry count are parameters.

Problem 3. The ITLB, rtl/mmu/itlb.
  Build it from itlb_decisions.md, itlb_ifu_interfaces.md and
  itlb_l2tlb_interfaces.md, with the PMP/PMA checker instantiated
  beside it (MMU-10a), against a testbench model of the L2 TLB.
  Accept, each with a check:
  - hit, miss and fault answers on the IFU port, including the
    reserved-status and unexpected-cause rule of IT-4;
  - non-blocking: hits continue while a walk is outstanding
    (ITLB-8); a re-request matching an in-flight walk starts no
    second walk (ITLB-10, IT-9); retry from the L2 TLB is re-asked
    (IL-6);
  - all four page sizes, with the 64 KiB NAPOT entry matched across
    its range and PPN[3:0] substituted on output (ITLB-3, IL-7);
  - ASID, global, VMID and V matching (ITLB-4, ITLB-4a);
  - the permission check on every hit: one entry that is legal and
    then faults after a privilege change with no fence (ITLB-16);
  - the effective PMA and PBMT on the IFU port (IT-10, ITLB-3a);
  - every invalidate form of ITLB-13, ITLB-13a and ITLB-13b, with
    the global rule of each; an invalidate during a walk installs
    nothing (IL-13, IL-14);
  - two lookups for a page-crossing block, tag returned
    (IT-1 to IT-3);
  - the invalidate port list you built, written into Results
    Capture as proposed text for itlb_decisions.md ITLB-14.

Problem 4. Decode on ifu_pd_pkt_t, TD#143.
  instr_decoder takes ifu_pd_pkt_t on all 8 slots and meets DCD-17

Problem 6. The front-end top, rtl/core/frontend/fe_top.
